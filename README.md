# L1 start: your first tiny feature

This branch is an empty starting point for **L1: Setup** in the [Spec Kit Developer Guide](https://tosin2013.github.io/invoice-exception-desk/L1-setup.html).

What to do:
1. Install the CLI: `uv tool install specify-cli`
2. Initialise here: `specify init --here --integration opencode`
3. Follow "Your first tiny feature" on the L1 page. You (or a strong model) write the constitution, spec, and plan; OpenCode's free model runs `/speckit.tasks` and `/speckit.implement`; a different reviewer checks the result.

The finished result is on the `l1-solution` branch.
